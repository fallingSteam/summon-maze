# 怪物图鉴

## 概述

迷宫中的怪物是虚空能量凝聚而成的生物，各具特色。怪物被击败后有概率被提取为亡灵。本文件记录迷宫中出现的所有怪物类型。

---

## 怪物分级

| 级别 | 标识颜色 | 属性倍率 | 技能数量 | 提取基础概率 | 出现层级 |
|------|----------|----------|----------|-------------|----------|
| 普通 | ⚪ 白色 | ×1.0 | 1 | 40% | 全部层级 |
| 精英 | 🔵 蓝色 | ×1.5 | 2 | 25% | 全部层级 |
| 精英小 Boss | 🔴 深红 | ×2.0-2.8 | 2-3 | 18% | 路线精英节点 |
| 稀有 | 🟣 紫色 | ×2.0 | 2-3 | 15% | 第 2 层+ |
| Boss | 🟡 金色 | ×3.0-5.0 | 3-4 | 10% | 每章终点 |
| 隐藏/闪光 | 🌈 彩虹 | ×1.3 | 2 | 15% | 随机（1% 出现率） |

### 附加说明
- **闪光怪**：任何普通/精英怪有 1% 概率以"闪光"形态出现，击败后 100% 可提取（无视概率）
- **稀有怪**：特定条件才会出现的特殊怪物，通常需要满足隐藏条件
- **精英怪**：比普通怪更大、属性更高、有独特外观
- **精英小 Boss**：路线中的高风险节点，拥有小型机制循环和更高奖励

## 怪物AI行为模式

| 行为模式 | 描述 | 典型怪物 |
|----------|------|----------|
| **激进型** | 优先攻击血量最低的单位 | 暗影狼、骷髅兵 |
| **策略型** | 优先攻击最危险的目标（高输出单位） | 观察者、堕落法师 |
| **保护型** | 优先攻击威胁己方后排的单位 | 骸骨骑士、dire熊 |
| **随机型** | 随机选择目标 | 虚空碎片、扭曲行者 |
| **Boss型** | 按照固定的技能循环行动 | 所有 Boss |
| **条件型** | 根据特定条件改变行为 | 美杜莎蛇（HP<50% 狂暴） |

## Demo 小怪技能与意图设计

### 设计目标

当前 Demo 中每个怪物拥有 3-4 个可预告技能。战斗界面应在敌人头顶或血条附近显示“怪物意图”，让玩家能提前判断本回合威胁，决定是否防御、集火、提取标记或优先击杀。

### 意图显示规则

| 意图类型 | UI 显示 | 玩家可读信息 |
|----------|---------|--------------|
| 攻击 | 红色剑刃 + 预计伤害 | 敌人将造成直接伤害 |
| 多段攻击 | 红色双刃 + 段数与总伤害 | 格挡收益更高，适合提前防御 |
| 防御/护盾 | 蓝色盾牌 + 护盾值 | 敌人将变硬，适合集火或等待 |
| 强化 | 金色上箭头 + Buff 名称 | 敌人后续回合会更危险 |
| 控制 | 紫色眼睛/锁链 + 状态名 | 可能限制行动、抽牌、能量或站位 |
| 召唤 | 暗绿色法阵 + 召唤物名称 | 敌方数量会增加，需要 AOE 或快速击杀 |
| 特殊 | 灰紫色虚空标记 + 简短描述 | 不稳定或规则外效果 |

### Demo 实现优先级

1. 第一版先实现“意图预告 + 技能效果差异”，不必一次实现所有复杂状态。
2. 状态效果可先用简化版本：护盾、强化、虚弱、易伤、中毒、灼烧、弃牌、少抽牌。
3. 每个怪物每回合根据技能权重选择下一技能，并在玩家回合开始时显示意图。
4. 精英和 Boss 后续再使用固定技能循环，普通怪以权重 AI 为主。
