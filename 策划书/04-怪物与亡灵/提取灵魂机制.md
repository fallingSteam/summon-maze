# 提取灵魂机制

## 概述

**提取灵魂（Soul Extraction）** 是 Summon Maze 最核心的机制，也是游戏差异化体验的关键。这是主人公将击败的怪物转化为亡灵队友的唯一途径。

---

## 触发条件

### 必须满足的条件
1. 怪物必须由**主人公亲自击杀**（亡灵击杀不触发提取判定）
2. 玩家当前备战亡灵数量未达上限，或愿意替换旧亡灵
3. 同名怪物亡灵未被持有（同名提取自动转为灵魂碎片）

### 不触发的情况
- 亡灵击杀的怪物
- DoT 伤害（中毒、灼烧、流血）击杀的怪物
- Boss 已被成功提取过一次
- 备战槽位已满且玩家不愿替换旧亡灵

---

## 提取概率公式

### 完整公式

```
P(提取成功) = 基础提取率 × (1 + 魔法上限 × 0.001 + 魔法强度 × 0.003) × 难度系数 × (1 + 迷宫层级 × 0.02) × 特殊系数
```

### 各参数详解

#### 1. 基础提取率（怪物品质决定）

| 怪物品质 | 基础提取率 |
|----------|-----------|
| 普通 | 40% |
| 精英 | 25% |
| 稀有 | 15% |
| Boss | 10% |
| 闪光 | 100%（固定） |

#### 2. 主人公属性加成

| 属性 | 系数 | 说明 |
|------|------|------|
| 魔法上限（MP） | ×0.001 | 每 100 点 MP 提供 10% 加成 |
| 魔法强度（MAG） | ×0.003 | 每 10 点 MAG 提供 3% 加成 |

**计算示例**：MP=200, MAG=30
- 属性加成 = 1 + 200 × 0.001 + 30 × 0.003 = 1 + 0.2 + 0.09 = 1.29

#### 3. 难度系数（怪物决定）

| 怪物类型 | 难度系数 | 设计意图 |
|----------|----------|----------|
| 普通怪 | ×1.0 | 基准 |
| 精英怪 | ×0.7 | 较强怪物更难提取 |
| 稀有怪 | ×0.5 | 稀有怪更难捕获 |
| Boss | ×0.4 | Boss 提取是巨大奖励 |
| 亡灵族 | ×1.1 | 同为亡灵，更容易共鸣 |
| 虚空族 | ×0.7 | 虚空生物难以锚定 |

#### 4. 迷宫层级加成

```
层级加成 = 1 + 当前层级 × 0.02
```

- 第 1 层：1.02（+2%）
- 第 2 层：1.04（+4%）
- 第 3 层：1.06（+6%）

> 深层迷宫魔法浓度更高，灵魂更容易被锚定。

#### 5. 特殊系数

| 条件 | 系数 | 说明 |
|------|------|------|
| 目标有"灵魂标记" | ×1.15 | 灵魂鞭笞技能施加 |
| 装备"灵魂水晶"遗物 | ×1.10 | 遗物加成 |
| 副职业为牧师 | ×1.10 | 被动加成 |
| 目标处于"虚弱"状态 | ×1.05 | 特定减益状态 |
| 使用"灵魂碎片"强化 | ×1.0 + 0.05×碎片数 | 战斗中使用碎片临时提升（消耗品） |
| 目标 HP 低于 10% 时击杀 | ×1.10 | "濒死提取"加成 |
| 目标被暴击击杀 | ×1.05 | "暴击提取"加成 |

## 提取流程

### 战斗内流程

```
┌──────────────────────────────────────────────┐
│              怪物被主人公击杀                   │
│                    ↓                          │
│         判定提取触发条件（是否满足）              │
│              ↓               ↓                │
│            满足             不满足              │
│              ↓               ↓                │
│         计算提取概率      获得灵魂碎片           │
│              ↓                                │
│       ┌────┴────┐                             │
│     成功        失败                           │
│       ↓          ↓                            │
│   提取动画    获得灵魂碎片                       │
│       ↓                                       │
│   获得亡灵！                                   │
└──────────────────────────────────────────────┘
```

### 提取成功时

1. **时间减缓效果**：画面进入慢动作
2. **灵魂浮现**：怪物的灵魂从尸体上浮现（暗紫色半透明轮廓）
3. **提取动作**：主人公伸出手，灵魂被吸入掌心
4. **UI 弹出**：
   ```
   ╔══════════════════╗
   ║  🌟 提取成功！    ║
   ║                  ║
   ║  获得亡灵：       ║
   ║  ☠️ 骸骨骑士     ║
   ║  品质：精英(蓝)   ║
   ║  等级：8         ║
   ║                  ║
   ║  [查看详情]      ║
   ║  [加入编队]      ║
   ║  [稍后处理]      ║
   ╚══════════════════╝
   ```
5. **音效**：低沉的嗡鸣声 + 灵魂回响音效
6. 如果是稀有/Boss 提取成功，增加特殊演出效果

### 提取失败时

1. 怪物灵魂浮现但随即破碎
2. 碎片飞入主人公手中
3. UI 提示获得灵魂碎片
4. 音效：玻璃破碎音效

## 灵魂碎片系统

### 碎片用途

| 用途 | 消耗碎片 | 效果 |
|------|----------|------|
| 亡灵注入 | 10/次 | 永久提升亡灵全属性 +1 |
| 商店兑换 | 30-100 | 兑换特定亡灵或物品 |
| 技能强化 | 20 | 为主人公技能提供临时加成 |
| 忠诚度恢复 | 15 | 恢复亡灵忠诚度 20 点 |
| 灵魂保护 | 50 | 下次探索保留一只亡灵（Roguelike 继承） |

### 碎片品级

| 品级 | 来源 | 价值倍率 |
|------|------|----------|
| 普通碎片 | 普通怪物 | ×1 |
| 精英碎片 | 精英怪物 | ×3 |
| 稀有碎片 | 稀有怪物 | ×8 |
| Boss 碎片 | Boss | ×20 |

碎片的品级影响其在商店中的购买力和强化效果。

## 提取策略深度

### 提高提取率的战术选择

1. **属性投资**：优先提升 MAG 和 MP 以增加提取概率
2. **技能搭配**：使用"灵魂鞭笞"标记目标后再击杀
3. **时机选择**：在目标 HP 极低时使用高伤害技能一击击杀（濒死加成 + 暴击加成）
4. **遗物组合**：装备增加提取率的遗物
5. **副职业选择**：牧师天然 +10% 提取率
6. **章节推进**：后续章节的魔法浓度略高，提取率小幅提升

### 资源管理决策

| 决策点 | 权衡 |
|--------|------|
| 是否亲自击杀 | 主人公亲自击杀触发提取 vs 亡灵击杀更快结束战斗 |
| 是否标记目标 | 消耗 MP 使用灵魂鞭笞 vs 保留 MP 给其他技能 |
| 是否使用碎片 | 消耗碎片临时提升提取率 vs 保留碎片用于亡灵强化 |
| 释放哪只亡灵 | 备战槽位已满时的痛苦抉择 |
| 优先提取哪种怪物 | 品质优先 vs 阵容需求优先 |

### 提取优先级建议

1. **S 级优先**：闪光怪物（100% 提取，绝对优先）
2. **A 级优先**：Boss（稀有，强力，错过不再有）
3. **B 级优先**：稀有怪物（强大亡灵）
4. **C 级优先**：阵容中缺少的定位（如缺坦克则优先提取前排怪物）
5. **D 级优先**：精英怪物（提升军团整体实力）
6. **普通**：前期填充阵容，后期若非特别需要可让亡灵击杀
