# 属性与成长

## 主人公属性详解

### 攻击力（ATK）
- **作用**：影响物理伤害输出、物理技能伤害
- **基础成长**：每级 +1
- **提升途径**：
  - 升级（自动）
  - 装备武器
  - 自由属性点分配
  - 遗物加成
  - 亡灵协同加成
- **软上限**：50（超过后成长减半）
- **硬上限**：99

### 防御力（DEF）
- **作用**：减少受到的物理伤害，每点 DEF 减少 0.5% 物理伤害（上限 60%）
- **基础成长**：每级 +1
- **提升途径**：
  - 升级（自动）
  - 装备防具
  - 自由属性点
  - 遗物加成
- **软上限**：40
- **硬上限**：80

### 敏捷（AGI）
- **作用**：
  - 决定行动顺序（AGI 越高，每回合越早行动）
  - 每点 AGI +0.3% 暴击率
  - 每点 AGI +0.2% 闪避率
- **基础成长**：每级 +1
- **提升途径**：
  - 升级（自动）
  - 装备饰品
  - 自由属性点
  - 遗物加成
- **软上限**：45
- **硬上限**：80

### 魔法强度（MAG）
- **作用**：
  - 影响魔法伤害输出
  - 影响亡灵强化效果
  - 影响治疗量
  - 影响提取灵魂概率
- **基础成长**：每级 +1.2
- **提升途径**：
  - 升级（自动）
  - 装备武器（法系武器）
  - 自由属性点
  - 遗物加成
- **软上限**：55
- **硬上限**：120

### 魔法上限（MP）
- **作用**：
  - 魔力池上限
  - 影响亡灵维持的可持续回合数
  - 影响提取灵魂概率
  - 影响部分技能的强度
- **基础成长**：每级 +10
- **提升途径**：
  - 升级（自动）
  - 装备（法袍、饰品）
  - 遗物加成
- **软上限**：300
- **硬上限**：500

### 生命值（HP）
- **作用**：生存，归零 = 游戏结束
- **基础成长**：每级 +15
- **提升途径**：
  - 升级（自动）
  - 装备防具
  - 遗物加成
- **软上限**：400
- **硬上限**：800

## 自由属性点系统

### 获取方式
- 每升 2 级获得 1 点
- 特定事件奖励
- 部分遗物提供额外属性点

### 分配规则
- 每点自由属性可提升：
  - ATK +2
  - DEF +2
  - AGI +2
  - MAG +3（法术系加成更高，体现死灵召唤师的法术天赋）
  - MP +15
  - HP +25

### 推荐分配策略

| 副职业 | 优先属性 | 次要属性 | 说明 |
|--------|----------|----------|------|
| 战士 | ATK、HP | DEF | 生存与输出并重 |
| 法师 | MAG、MP | — | 极致魔法输出 |
| 刺客 | AGI、ATK | HP | 速度与爆发 |
| 牧师 | MAG、MP | HP | 治疗量与生存 |
| 弓箭手 | AGI、ATK | — | 高速精准打击 |

## 属性阈值效果

某些属性达到特定阈值时，会解锁额外效果：

| 属性 | 阈值 | 解锁效果 |
|------|------|----------|
| ATK | 30 | **破甲**：攻击无视目标 10% DEF |
| ATK | 50 | **粉碎**：攻击有 15% 概率击碎目标护盾/增益 |
| DEF | 30 | **坚韧**：受到致命伤害时 10% 概率保留 1 HP |
| DEF | 50 | **铁壁**：每回合自动获得 MAG×0.3 的护盾 |
| AGI | 30 | **先制**：战斗开始时必定第一个行动 |
| AGI | 50 | **幻影**：每场战斗自动闪避第一次受到的攻击 |
| MAG | 40 | **魔力渗透**：魔法伤害无视目标 15% 魔抗 |
| MAG | 70 | **魔力风暴**：每第 4 次使用技能后，下个技能不消耗 MP |
| MP | 200 | **魔力源泉**：每回合开始恢复 5% 最大 MP |
| MP | 350 | **无限魔力**：亡灵维持消耗减半 |

## 亡灵成长系统

### 亡灵等级
- 亡灵初始等级 = 被提取时怪物的等级
- 亡灵最高等级 = 主人公当前等级 + 2
- 亡灵升级所需经验 = 主人公同等级所需经验的 80%

### 亡灵升级收益
- 每升 1 级：HP +8%，ATK +5%，DEF +3%
- 每升 3 级：解锁或强化一个技能
- 每升 5 级：获得一次进化机会（需要消耗特殊道具）

### 亡灵进化
- 普通亡灵可进化 1 次（变为精英品质）
- 精英亡灵可进化 1 次（变为稀有品质）
- Boss 亡灵不可进化（但可通过特殊事件强化）
- 进化后外观变化、属性大幅提升、解锁新技能

### 亡灵忠诚度
- 初始忠诚度：50（受提取时概率影响，高概率提取 = 高忠诚度）
- 忠诚度影响：
  - 战斗中听从指令的概率（低忠诚度可能自主行动）
  - 伤害输出加成（100 忠诚度时 +15% 伤害）
  - 被动技能触发概率
- 提升方式：
  - 一起战斗（每场 +1-3 点）
  - 使用亡灵喜欢的道具
  - 特定事件选择
- 降低条件：
  - 战斗中阵亡（-15 点）
  - 长时间不出战（每探索 3 层 -5 点）
  - 被献祭（该亡灵直接消失）

## 成长曲线设计

### 前期（1-5级）
- 属性基数低，成长快
- 每次升级感觉明显
- 亡灵数量少（3-4 个），阵容搭配简单

### 中期（6-12级）
- 属性进入稳定增长期
- 亡灵军团规模扩大（5-6 个）
- 开始需要考量阵容搭配
- 怪物强度提升，策略性增强

### 后期（13-18级）
- 属性接近软上限，成长放缓
- 亡灵军团成型（7-8 个）
- 遗物和装备成为主要提升来源
- 高难度战斗需要精细操作

### 最终阶段（19-20级）
- 属性达到或接近硬上限
- 亡灵军团完全体
- 为最终 Boss 战做最后准备
- 战斗结果取决于策略而非数值
