# 位置与空间机制

## 概述

Summon Maze 的战斗采用 **1-4 号位** 的站位系统，敌我双方各有 4 个位置。站位影响行动顺序、技能的使用范围、目标选择和战术策略。

**核心设计理念**：我方与敌方均使用相同的 4 格站位。每场战斗我方最多为 **主人公 + 3 名亡灵**。我方单位按从左到右依次行动，因此站位既是空间策略，也是行动顺序策略。

---

## 战场布局

```
        敌方                                我方
  ┌──────┬──────┬──────┬──────┐    ┌──────┬──────┬──────┬──────┐
  │  4   │  3   │  2   │  1   │    │  1   │  2   │  3   │  4   │
  │ 号位  │ 号位  │ 号位  │ 号位  │    │ 号位  │ 号位  │ 号位  │ 号位  │
  └──────┴──────┴──────┴──────┘    └──────┴──────┴──────┴──────┘
       ← 敌方后排    敌方前排 →          ← 我方前排    我方后排 →

  行动顺序：         我方 [1] → [2] → [3] → [4]
  近战攻击范围：     相邻位置（1↔2, 2↔3, 3↔4）
  远程攻击范围：     任意位置
  特殊范围：         穿透（1→2→3），跳跃（1→3），全体等
```

### 位置编号规则
- **我方**：1 号位最靠近敌人，4 号位最远
- **敌方**：1 号位最靠近我方，4 号位最远
- 同编号位置（如我方 1 号位和敌方 1 号位）为"对峙位"

---

## 站位规则

### 基础规则
1. 每个位置只能有 **1 个单位**（主人公或亡灵或敌人）
2. 我方最多 4 个单位：主人公 + 最多 3 名亡灵
3. 战斗开始前，玩家从备战槽位中选择最多 3 名亡灵并安排站位
4. 战斗中可以通过"切换站位"行动与相邻友方交换位置

### 战斗间出战选择
- 备战槽位最高 8，用于保存当前探索可用的亡灵池。
- 每场战斗前只能从备战槽位中选择最多 3 名亡灵出战。
- 未出战亡灵不会进入本场战斗，也不会自动补位。
- 提取到新亡灵后，可在战斗结束后的整备阶段调整下一场阵容。

### 位置与技能范围

#### 攻击范围类型

| 范围类型 | 图示 | 说明 | 典型技能 |
|----------|------|------|----------|
| 近战单体 | 相邻 1 个位置 | 只能攻击相邻位置的敌人 | 普通近战攻击、猛击 |
| 远程单体 | 任意 1 个位置 | 可攻击敌方任意位置 | 精准射击、奥术飞弹 |
| 前排横扫 | 敌方 1-2 号位 | 攻击敌方前排范围 | 旋风斩、横扫 |
| 后排狙击 | 敌方 3-4 号位 | 攻击敌方后排范围 | 狙击、暗杀 |
| 贯穿 | 直线穿透 | 从自身位置贯穿同列敌人 | 穿刺射击、暗影突刺 |
| 全体 AOE | 敌方全体 | 攻击敌方所有位置 | 暴风雪、陨石术、箭雨 |
| 跳跃攻击 | 跳跃到指定位置 | 可选择攻击任意位置，但自身位置改变 | 暗影步 |
| 随机 | 随机目标 | 随机选择 1-N 个敌方目标 | 混沌箭 |

#### 施放位置要求

| 技能类型 | 施放者位置要求 | 示例 |
|----------|---------------|------|
| 前排技能 | 必须在 1-2 号位 | 猛击、战吼、旋风斩 |
| 后排技能 | 必须在 3-4 号位 | 精准射击、奥术飞弹 |
| 任意位置 | 无位置限制 | 治愈之光、站起来 |
| 边缘技能 | 必须在 1 号位或 4 号位 | 暗杀、狙击 |

## 战术深度

### 阵型搭配策略

#### 1. 均衡阵型（推荐新手）
```
1 号位：坦克型亡灵（高 DEF/HP）
2 号位：战士型亡灵（均衡攻防）
3 号位：主人公（视副职业而定）
4 号位：远程/法师型亡灵
```
- **优点**：攻守均衡，容错率高
- **缺点**：缺乏特化优势

#### 2. 前排压制阵型
```
1 号位：高 ATK 战士亡灵
2 号位：高 ATK 战士亡灵
3 号位：主人公（战士/刺客）
4 号位：支援型亡灵
```
- **优点**：前排输出爆炸，快速消灭威胁
- **缺点**：后排脆弱，被 AOE 克制

#### 3. 后排轰炸阵型
```
1 号位：坦克亡灵
2 号位：控制型亡灵
3 号位：主人公（法师/弓箭手）
4 号位：法师型亡灵
```
- **优点**：远程火力压制，安全输出
- **缺点**：前排压力大，坦克被破则崩盘

#### 4. 三亡灵压制阵型
```
1 号位：坦克亡灵
2 号位：输出亡灵
3 号位：控制/辅助亡灵
4 号位：主人公（后排指挥）
```
- **优点**：亡灵数量优势，协同效果最大化
- **缺点**：主人公行动较晚，遇到高爆发敌人时风险较高

### 位置破坏与强制移动

部分技能可以改变敌方位置：
- **击退（Push）**：将目标向敌方后排方向移动（1→2→3→4）
- **拉扯（Pull）**：将目标向我方方向移动（4→3→2→1）
- **换位（Swap）**：强制与目标交换位置

**战术应用**：
- 将敌方后排脆皮拉扯到前排进行集火
- 将敌方前排坦克击退到后排，使其技能失效
- 破坏敌方阵型协同
