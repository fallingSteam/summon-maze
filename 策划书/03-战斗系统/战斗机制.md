# 战斗机制

## 概述

Summon Maze 的战斗系统采用**回合制位置战斗**。玩家在战斗中控制主人公和最多 3 名亡灵队友，每个单位都有自己的行动回合和独立技能。战斗重点从“主人公指挥一群自动随从”调整为“小队战术回合制”：主人公和亡灵都能被玩家主动操作。

---

## 战斗触发

### 触发方式
- **战斗房**：普通怪物战斗
- **精英小 Boss 房**：路途中遇到的强敌节点，参考《杀戮尖塔》的精英路线选择
- **事件触发**：特定事件导致强制战斗
- **章节 Boss 战**：每章终点 Boss，当前版本共 3 个章节 Boss

### 战斗开始流程
1. 屏幕过渡动画（暗影笼罩效果）
2. 展示敌人阵容与位置
3. 玩家确认本场出战单位：**主人公 + 最多 3 名亡灵**
4. 将出战单位按从左到右的队列摆放
5. 进入回合循环

---

## 回合结构

每个回合分为以下阶段：

### 阶段 1：回合开始阶段（Start Phase）
- 持续效果（DoT、HoT、Buff/Debuff）触发
- MP 自然恢复（主人公 MP 上限的 3%）
- 亡灵维持消耗结算
- “回合开始”类遗物效果触发

### 阶段 2：我方行动阶段（Ally Phase）
- 我方单位按**从左到右**依次行动
- 行动队列包含主人公与本场出战亡灵
- 每个单位拥有独立行动回合，轮到该单位时可使用自己的普通攻击、技能、道具或防御
- 亡灵不再只是自动攻击单位，而是与主人公一样拥有可选择的技能
- 如开启自动模式，亡灵可根据 AI 模式自动选择技能与目标

### 阶段 3：敌人行动阶段（Enemy Phase）
- 敌方单位同样按**从左到右**依次行动
- 精英小 Boss 与章节 Boss 使用固定或半固定技能循环，方便玩家预判
- 普通敌人按 AI 行为模式选择目标和技能

### 阶段 4：回合结束阶段（End Phase）
- 结算“回合结束”类效果
- 检查战斗结束条件
- 更新状态持续时间

## 敌人意图系统

为强化卡牌式战斗决策，敌人在玩家行动阶段应显示下一次行动意图。玩家看到意图后，可以决定本回合是优先防御、击杀、控制、提取标记，还是保留资源等待下一轮。

### 基础规则

- 每个敌人拥有 3-4 个技能。
- 敌人在自己行动结束后，或新一轮玩家行动开始前，决定下一次技能。
- 玩家回合中显示该技能的意图：攻击、防御、强化、控制、召唤或特殊。
- 意图至少显示：技能类型、预计伤害或主要效果。
- 若敌人被眩晕、沉默或其他控制影响，意图应更新为“跳过”“普通攻击”或“技能失败”。

### UI 信息层级

| 层级 | 显示内容 | 示例 |
|------|----------|------|
| 必须显示 | 意图类型 + 数值 | 攻击 18、防御 12、控制：缠绕 |
| 建议显示 | 技能名称 | 骨箭射击、虚空侵蚀 |
| 可选显示 | 目标倾向 | 攻击后排、保护后排、全体伤害 |

### 与卡牌战斗的关系

- 当敌人预告高伤害时，防御牌和护盾装备价值上升。
- 当敌人预告防御时，玩家可以选择积累资源、抽牌或转火其他目标。
- 当敌人预告控制时，玩家可以优先击杀或用亡灵承伤。
- 当敌人预告召唤或 AOE 时，玩家需要考虑范围牌和亡灵站位。

## 行动系统

### 单位行动

每个单位在自己的行动回合内执行 **1 个主要行动**：

| 行动类型 | 说明 |
|----------|------|
| 普通攻击 | 使用该单位的基础攻击 |
| 使用技能 | 使用主人公技能或亡灵自带技能 |
| 使用道具 | 消耗一个战斗道具（默认仅主人公可用，遗物可扩展） |
| 防御 | 本轮受到伤害降低，适合承受 Boss 预告技能 |
| 切换站位 | 与相邻我方单位交换位置 |
| 等待 | 跳过本次行动 |

### 行动顺序

行动顺序固定为**从左到右**：

```
我方队列：[1] → [2] → [3] → [4]
敌方队列：[1] → [2] → [3] → [4]
```

- 队列 1-4 号位从左到右显示
- 主人公可以放在任意我方位置
- 每场战斗最多 4 个我方单位：主人公 + 最多 3 个亡灵
- AGI 不再决定基础行动顺序，而是影响暴击、闪避、先制率和部分技能效果
- “先制”状态可以让指定单位在本回合提前至队列最左侧行动
- “眩晕”“睡眠”等控制状态会让对应单位跳过自己的行动回合

### 亡灵技能

每个亡灵拥有独立技能组：

| 亡灵类型 | 技能数量 | 说明 |
|----------|----------|------|
| 普通亡灵 | 1 个主动技能 | 简单定位，如前排攻击、后排射击、单体控制 |
| 精英亡灵 | 2 个主动技能 | 有明确战术定位和冷却管理 |
| 稀有亡灵 | 2-3 个主动技能 | 具备强协同或特殊机制 |
| Boss 亡灵 | 3 个主动技能 + 1 个被动 | 强力但通常占用更多备战资源 |

## 战斗间准备

每场战斗结束后，进入短暂的**整备阶段**：

1. **属性加点**：从 2-3 个随机成长选项中选择 1 个，例如 ATK+2、MAG+2、最大 HP+15、最大 MP+10、某亡灵 ATK+2。
2. **选择出战亡灵**：从备战亡灵中选择最多 3 个进入下一场战斗。
3. **调整站位**：安排主人公和亡灵从左到右的位置。
4. **查看敌情**：若下一节点已知，显示房间类型和大致威胁。

该设计让“提取到新亡灵”能立刻转化为编队决策，而不是只在长期养成界面中生效。

## 伤害计算

### 物理伤害公式
```
基础伤害 = 攻击方 ATK × 技能倍率
减伤系数 = 1 - (防御方 DEF × 0.5%)      (上限 60%)
最终伤害 = 基础伤害 × 减伤系数 × 随机系数(0.9~1.1) × 克制系数 × 暴击系数
```

### 魔法伤害公式
```
基础伤害 = 攻击方 MAG × 技能倍率
减伤系数 = 1 - (防御方 MAG × 0.3%)      (上限 40%)
最终伤害 = 基础伤害 × 减伤系数 × 随机系数(0.9~1.1) × 克制系数 × 暴击系数
```

### 暴击判定
```
暴击率 = 基础暴击率 + AGI × 0.3% + 装备加成 + 状态加成 - 目标抗暴率
暴击伤害 = 1.5 + 暴击伤害加成（装备/遗物）
```

### 命中判定
```
基础命中率 = 95%
实际命中率 = 基础命中率 + 命中加成 - 目标闪避率
（上限 100%，下限 10%）
```

## 元素与克制系统

### 伤害元素

| 元素 | 代表颜色 | 典型使用者 | 克制 | 被克制 |
|------|----------|-----------|------|--------|
| 🔴 物理 | 灰色 | 战士、弓箭手 | — | 高 DEF 单位 |
| 🟣 暗影 | 暗紫色 | 亡灵、死灵法师 | 神圣 | 暗影 |
| 🟡 神圣 | 金色 | 牧师、天使 | 暗影 | 混沌 |
| 🔵 冰霜 | 冰蓝色 | 冰系怪物、部分法师 | 火焰 | 冰霜 |
| 🟠 火焰 | 橙红色 | 火系怪物、部分法师 | 冰霜 | 火焰 |
| 🟢 自然 | 绿色 | 自然系怪物 | 混沌 | 火焰 |
| ⚫ 混沌 | 暗红色 | 虚空生物 | — | 神圣/自然 |

### 克制系数
- 克制：伤害 × 1.5
- 被克制：伤害 × 0.75
- 同元素：伤害 × 0.5
- 无克制关系：伤害 × 1.0

## 状态效果大全

### 正面状态（Buff）

| 状态 | 效果 | 典型持续回合 | 可叠加 |
|------|------|-------------|--------|
| 攻击提升 | ATK +X% | 2-3 | 是（最多 3 层） |
| 防御提升 | DEF +X% | 2-3 | 是（最多 3 层） |
| 速度提升 | AGI +X% 或提前行动 | 2-3 | 否 |
| 魔力涌动 | MAG +X% | 2-3 | 是（最多 2 层） |
| 护盾 | 吸收 X 伤害 | 3 | 否（取最高值） |
| 再生 | 每回合恢复 X HP | 3 | 否（取最高值） |
| 免疫 | 免疫特定负面状态 | 1-3 | 否 |
| 隐身 | 无法被单体技能选中 | 1-2 | 否 |
| 嘲讽 | 强制敌人攻击自身 | 2 | 否 |
| 反击 | 受到攻击时反击 | 2-3 | 否 |

### 负面状态（Debuff）

| 状态 | 效果 | 典型持续回合 | 可叠加 |
|------|------|-------------|--------|
| 攻击降低 | ATK -X% | 2-3 | 是（最多 3 层） |
| 防御降低 | DEF -X% | 2-3 | 是（最多 3 层） |
| 减速 | AGI -X% 或行动延后 | 2-3 | 是（最多 2 层） |
| 中毒 | 每回合失去 X HP | 3-4 | 是 |
| 灼烧 | 每回合失去 X HP | 3 | 是（最多 3 层） |
| 流血 | 每回合失去 X HP | 2-3 | 是 |
| 眩晕 | 跳过自己的行动回合 | 1 | 否 |
| 定身 | 无法切换站位但可行动 | 1-2 | 否 |
| 沉默 | 无法使用技能 | 1-2 | 否 |
| 混乱 | 随机选择目标和行动 | 1-2 | 否 |
| 恐惧 | 强制向后移动并跳过行动 | 1 | 否 |
| 睡眠 | 跳过行动，受到攻击后醒来 | 2-3 | 否 |
| 凋零 | 每回合失去最大 HP 的 X% | 3 | 否 |
| 灵魂标记 | 死亡时提取灵魂概率 +X% | 2 | 否 |

### 特殊状态

| 状态 | 效果 |
|------|------|
| 亡灵化 | 单位被视为亡灵类型，受亡灵相关效果影响 |
| 虚空侵蚀 | 每回合随机失去一种 Buff，获得一个随机 Debuff |
| 灵魂链接 | 伤害由链接单位分摊 |
| 不屈 | HP 不能低于 1 |
| 即死抗性 | 免疫即死效果（Boss 固有） |

## 战斗结束

### 胜利条件
- 敌方全灭
- 精英小 Boss / 章节 Boss 被击败

### 失败条件
- 主人公 HP 归零（游戏结束）
- 逃跑失败后全灭

### 战斗奖励

| 奖励类型 | 基础值 | 影响因素 |
|----------|--------|----------|
| 经验值 | 怪物基础经验总和 | 章节、节点类型、遗物加成 |
| 金币 | 怪物基础金币总和 | 章节、节点类型、遗物加成 |
| 灵魂提取 | 每个怪物独立判定 | 提取概率公式 |
| 灵魂碎片 | 必定获得（根据怪物等级） | 怪物等级 |
| 掉落装备 | 概率掉率 | 怪物等级、稀有度、遗物加成 |
| 属性加点 | 战斗后选择 1 项 | 节点强度、遗物、事件 |

### 灵魂碎片
提取灵魂失败时，获得“灵魂碎片”作为保底：
- 可用于在商店兑换亡灵
- 可用于强化现有亡灵
- Boss 灵魂碎片可用于制作特殊遗物

---

## 逃跑机制

- 使用行动回合尝试逃跑
- 逃跑成功率 = 50% + AGI 差 × 2%（与敌方最高 AGI 比较）
- 章节 Boss 战不可逃跑
- 精英小 Boss 战逃跑成功率减半
- 逃跑成功后返回地图节点（该房间保持“已探索”状态）
- 逃跑失败后本单位行动结束
