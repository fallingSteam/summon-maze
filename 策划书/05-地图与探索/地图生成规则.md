# 地图生成规则

## 概述

每层迷宫的地图是**程序化随机生成**的节点图，参考《杀戮尖塔》的路线选择。当前版本将内容量压缩为 **3 层 / 3 个章节**，每层代表一个章节，并在该层终点遭遇章节 Boss。

玩家从入口开始，沿着分叉路线选择 6-8 个节点中的一部分前进。路途中可能遇到普通战斗、事件、商店、休息点、宝箱，以及高风险高回报的**精英小 Boss 节点**。

---

## 地图结构

### 基础布局

```
                    ┌──────┐
                    │ Boss │  ← 章节终点
                    │  🟡  │
                    └──┬───┘
              ┌────────┴────────┐
              │                 │
           ┌──┴──┐           ┌──┴──┐
           │ 👹 │           │ 🏕️ │  ← 第 3 行
           └──┬──┘           └──┬──┘
              │       ┌────────┘
           ┌──┴──┐ ┌──┴──┐
           │ ⚔️ │ │ ❓ │        ← 第 2 行
           └──┬──┘ └──┬──┘
              │       │
              └──┬────┘
                 │
              ┌──┴──┐
              │ 🚪 │        ← 入口
              └─────┘
```

### 结构参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 总层数 | 3 层 | 每层对应一个章节 |
| 每层节点数 | 6-8 个 | 不包含入口，包含 Boss 节点 |
| 普通行数 | 3 行 | 不包括入口和 Boss 行 |
| 每行节点数 | 1-3 个 | 随机波动 |
| 分支因子 | 1-2 个 | 每个节点连接的下行节点数 |
| Boss 位置 | 最上行 | 固定为章节终点 |

## 生成规则

### 第 1 层：教学层

第 1 层仍保留轻量教学，但不再使用长流程固定地图。

```
入口 → 战斗(教学) → 事件(副职业选择) → 分支路线 → Boss
```

设计要求：
- 至少 1 个普通战斗节点
- 至少 1 个事件节点，用于副职业选择或教程提示
- Boss 前至少有 1 个恢复或奖励节点
- 首次提取教学安排在第 1 个普通战斗节点

### 第 2-3 层：标准层

#### 生成步骤

1. **确定节点数**：随机 6-8 个节点。
2. **生成 3 行分支**：
   - 每行 1-3 个节点
   - 保证至少 2 条可行路线
3. **分配节点类型**：
   - 每层至少 1 个普通战斗节点
   - 每层最多 1 个商店
   - 每层最多 1 个休息点
   - 每层 0-2 个精英小 Boss 节点
4. **生成连接线**：
   - 每个节点至少连接到下一行 1 个节点
   - 不允许孤岛节点
5. **平衡检查**：
   - 确保至少存在 1 条从入口到 Boss 的路线
   - 确保至少存在 1 条安全路线和 1 条高风险路线

#### 难度递增规则

| 层级/章节 | 精英小 Boss 概率 | 休息点概率 | 商店概率 | 说明 |
|-----------|------------------|-----------|----------|------|
| 第 1 层：觉醒 | 8% | 16% | 10% | 教学友好 |
| 第 2 层：深渊低语 | 16% | 12% | 10% | 正常难度 |
| 第 3 层：虚空之门 | 24% | 10% | 8% | 最终挑战 |

## 路径选择策略

玩家在入口处可以看到**整层地图**（除隐藏节点外），需要规划路线：

| 考量因素 | 说明 |
|----------|------|
| **战斗数量** | 更多战斗 = 更多经验、属性加点和提取机会，但消耗更多 HP/MP |
| **精英小 Boss** | 奖励强，可能掉落稀有遗物或高品质亡灵，但战斗风险高 |
| **休息点位置** | 血量不足时，优先选择通往休息点的路线 |
| **商店访问** | 金币充足时，优先通往商店路线 |
| **事件风险** | 随机事件可能获得强奖励，也可能带来诅咒 |
| **队伍状态** | 根据当前亡灵阵容选择适合的路线 |

### 路线类型

| 路线类型 | 特点 | 推荐场景 |
|----------|------|----------|
| **战斗路线** | 多普通战斗，稳定成长 | 前期发育、寻找新亡灵 |
| **安全路线** | 休息点、商店、宝箱较多 | HP/MP 不足时 |
| **精英路线** | 包含精英小 Boss | 阵容成型、想搏强力奖励 |
| **事件路线** | 随机性高 | 想搏流派变化 |
| **最短路线** | 节点少，直奔 Boss | 状态危险或速通 |

## 隐藏房间

### 触发条件

隐藏房间不会直接显示在地图上，需要满足以下条件之一才能发现：

1. **遗物效果**：装备特定遗物（如“探知之眼”）。
2. **技能探测**：某些通用技能可以探测隐藏房。
3. **高 AGI**：AGI ≥ 40 时有概率自动发现（AGI × 0.5% 概率）。
4. **特殊事件**：事件中可能揭示隐藏房位置。

### 隐藏房内容
- 必定包含高品质奖励。
- 可能有闪光怪物。
- 可能有特殊事件（仅隐藏房独有）。
