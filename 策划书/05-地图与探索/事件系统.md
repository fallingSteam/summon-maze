# 事件系统

## 概述

事件系统为迷宫探索提供**叙事深度**和**不可预测性**。当玩家进入 ❓ 随机事件节点时，会触发一个随机事件。事件通常以**文字冒险**的形式呈现，玩家需要从 2-4 个选项中做出选择。

---

## 事件结构

### 标准事件格式

```yaml
事件名称: 虚空中的回声
事件类型: 正面事件
出现条件: 迷宫第 6 层以上
稀有度: 普通

描述: >
  你在通道中听到了一阵低语声，声音似乎来自
  虚空的另一侧。墙壁上浮现出暗紫色的符文，
  发出微弱的光芒。你可以尝试解读这些符文，
  但不确定这会带来什么后果。

选项:
  1. 尝试解读符文 (MAG判定)
     - 成功(MAG≥30): 学会一个随机魔法技能
     - 失败: 受到 MAG×1.0 的暗影伤害
  
  2. 让亡灵触碰符文
     - 需要: 至少拥有一只亡灵族亡灵
     - 效果: 该亡灵永久 MAG+5, 忠诚度-10
  
  3. 无视并继续前进
     - 效果: 无任何效果（安全）

  4. 摧毁符文
     - 效果: 获得 10 灵魂碎片 + 可能激怒虚空(小概率进入战斗)
```

### 事件属性

| 属性 | 说明 |
|------|------|
| 名称 | 事件标题 |
| 类型 | 正面/负面/中性/剧情 |
| 出现条件 | 迷宫层级、持有亡灵、副职业等 |
| 稀有度 | 普通/稀有/传说（影响出现概率） |
| 描述 | 叙事文本 |
| 选项 | 2-4 个选择 |
| 判定 | 基于属性/持有物/随机 |
| 结果 | 增益/损失/战斗/获得物品 |

## 事件分类

### 一、正面事件（40%）

提供纯粹或主要正面效果的事件。

#### 例 1：迷途商人
```
你在通道中遇到了一个被困在迷宫中的商人。他看起来
筋疲力尽，但货物完好无损。他愿意以极低价格出售物品
以换取你的保护。

选项：
1. 购买打折商品（商店界面，全部 50% off）
2. 护送商人 → 商人加入你的队伍，在下次 Boss 战中提供一次免费复活
3. 抢劫商人 → 获得全部商品（免费）但获得负面遗物"诅咒金币"
```

#### 例 2：灵魂温泉
```
墙壁的裂缝中涌出温暖的魔法泉水，水中漂浮着
若隐若现的灵魂光点。泉水散发着令人安心的光芒。

选项：
1. 饮用泉水 → 恢复 50% HP & MP
2. 让亡灵浸泡 → 所有亡灵恢复全部 HP，忠诚度 +5
3. 收集泉水 → 获得消耗品"灵魂泉水"×2
4. 沐浴 → 永久 HP +10
```

#### 例 3：训练假人
```
你发现了一个古老的训练室，里面有永远不会损坏的
魔法假人。这里似乎是古代冒险者修行的地方。

选项：
1. 亲自训练 → 获得大量经验（主人公）
2. 训练亡灵 → 选择一只亡灵获得双倍经验
3. 战斗演练 → 全队获得中等经验
```

### 二、负面事件（20%）

提供惩罚或风险的事件，但有时也可能通过智慧选择规避。

#### 例 1：魔力漩涡
```
空间突然扭曲，一个魔力漩涡在你脚下形成！
魔力正在疯狂地被漩涡吞噬。

选项：
1. 全力抵抗（MAG判定）→ 成功：无事发生 / 失败：失去 50% MP
2. 让一只亡灵吸收漩涡 → 亡灵获得永久 MAG+8 但 HP 减半
3. 丢入金币分散漩涡 → 失去 50% 金币
4. 强行突破（HP判定）→ 受到 30% 最大HP伤害，但漩涡消失
```

#### 例 2：诅咒雕像
```
通道中央矗立着一座诡异的雕像，雕像手持天平，
眼睛散发着不祥的红光。雕像底座刻着文字：
"以汝之珍，换吾之赐"

选项：
1. 献上灵魂碎片 20 → 获得随机紫色遗物
2. 献上一只亡灵 → 全属性永久 +3
3. 献上 50% 金币 → 随机技能升级
4. 拒绝并离开 → 受到诅咒（本次探索 HP 上限 -15%）
```

#### 例 3：亡灵反噬
```
你的亡灵突然开始不受控制地颤抖，它们的灵魂链接
出现了剧烈的波动！

触发条件：忠诚度最低的亡灵忠诚度 < 40

选项：
1. 消耗 MP 压制（消耗 50 MP）→ 恢复控制，忠诚度 -5
2. 消耗灵魂碎片安抚（消耗 15 碎片）→ 忠诚度 +15
3. 释放该亡灵 → 失去该亡灵，获得碎片补偿
4. 强行战斗 → 与该亡灵战斗（赢了重新提取，输了永久失去）
```

### 三、中性/风险事件（25%）

高风险高回报，结局取决于判定或运气。

#### 例 1：灵魂赌场
```
一个身着华丽但破旧礼服的身影在通道中摆了一张桌子。
"来吧，试试运气！灵魂碎片是最佳的赌注。"

选项：
1. 押注 5 碎片 → 50% 赢得 15 碎片 / 50% 失去赌注
2. 押注 20 碎片 → 30% 赢得 100 碎片 / 70% 失去赌注
3. 押注一只亡灵 → 20% 升级为随机更高品质亡灵 / 80% 失去
4. 押注一件装备 → 50% 获得更好品质 / 50% 失去
5. 不赌 → 无事发生
```

#### 例 2：虚空裂隙
```
面前出现了一道虚空裂隙，你可以看到裂隙另一侧
有闪闪发光的宝物。但虚空能量正在侵蚀裂隙边缘，
它随时可能关闭。

选项：
1. 伸手捞取（AGI判定 30）→ 成功：随机紫色装备 / 失败：受到伤害
2. 让亡灵伸入 → 亡灵受到虚空侵蚀（获得永久 DEBUFF），但必定取回宝物
3. 投入灵魂碎片稳定裂隙 → 消耗 10 碎片，安全取得一件蓝色装备
4. 无视裂隙 → 无事发生
```

#### 例 3：谜之宝箱
```
通道尽头有一个精美的宝箱，但宝箱周围的地面上
有烧焦的痕迹和疑似骨骸的碎片。

选项：
1. 直接打开 → 70% 获得丰厚奖励 / 30% 爆炸（全队 25% HP 伤害）
2. 用工具撬锁（需拥有特定遗物）→ 安全打开
3. 让亡灵打开 → 亡灵受到最大 HP 50% 伤害，但宝箱安全打开
4. 仔细检查（AGI判定 25）→ 发现陷阱并解除，安全打开
5. 放弃 → 无事发生
```

### 四、剧情事件（15%）

推动主线或支线剧情的关键事件。

#### 例 1：守门人的记忆
```
你在休息时，守门人的影像突然出现在你面前。
"我想起了一些事...关于你的祖先莫迪斯..."

触发条件：第 5 层，已拥有至少 3 只亡灵

这是剧情关键节点，揭示莫迪斯与虚空意志的真正关系。
→ 观看剧情过场
→ 获得遗物"莫迪斯的记忆碎片"
```

#### 例 2：堕落者之殇
```
你在通道中发现了一个奄奄一息的冒险者。
他的身体已经开始虚空化，但意识仍然清醒。
"求求你...在我彻底变成怪物之前...结束这一切..."

触发条件：第 10 层以上

选项：
1. 满足他的请求（战斗：击败堕落冒险者）→ 获得遗物"英雄之证"
2. 尝试净化（MAG判定 40）→ 成功：冒险者获救，获得稀有亡灵"光明骑士"
3. 提取他的灵魂 → 必定获得亡灵"堕落冒险者"（精英品质）
4. 无视 → 获得负面遗物"内疚"
```

## 事件判定系统

### 判定类型

| 判定类型 | 公式 | 示例 |
|----------|------|------|
| 属性判定 | 属性值 ≥ 阈值 → 成功 | MAG ≥ 30 |
| 概率判定 | 随机 1-100 ≤ 成功率 → 成功 | 40% 成功率 |
| 拥有判定 | 检查是否持有某物品/亡灵 | 拥有亡灵族亡灵 |
| 职业判定 | 检查副职业 | 副职业=牧师 |
| 复合判定 | 多个条件组合 | AGI≥25 且拥有"盗贼工具" |

### 判定结果展示

```
┌─────────────────────────────────────────┐
│  🔮 尝试解读符文                         │
│                                          │
│  判定: MAG ≥ 30                         │
│  当前 MAG: 35 ✅                        │
│                                          │
│  结果: 成功！                            │
│  你成功解读了符文，学会了新技能：          │
│  ✨ [暗影护盾]                           │
└─────────────────────────────────────────┘
```

## 事件稀有度与出现概率

| 稀有度 | 出现概率 | 奖励规模 | 风险程度 |
|--------|----------|----------|----------|
| 普通 | 60% | 小型奖励/惩罚 | 低 |
| 稀有 | 30% | 中型奖励/惩罚 | 中 |
| 传说 | 8% | 大型奖励/惩罚 | 高 |
| 独有 | 2% | 唯一性物品/亡灵 | 极高 |

---

## 事件与遗物的交互

部分遗物可以修改事件选项或结果：

| 遗物 | 事件效果 |
|------|----------|
| 幸运兔脚 | 所有概率判定 +10% 成功率 |
| 探知之眼 | 显示每个选项的结果预览 |
| 商人徽章 | 所有商店/商人相关事件额外选项 |
| 灵魂水晶 | 灵魂相关事件奖励翻倍 |
| 诅咒娃娃 | 负面事件中出现"转移诅咒"额外选项 |
