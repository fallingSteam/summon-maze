# Summon Maze 核心玩法策划书 v0.1

## 1. 游戏概述

### 1.1 一句话定位

《Summon Maze》是一款面向 Steam 平台的 2D 像素黑暗奇幻 Roguelike 策略构筑游戏。玩家扮演一名冷酷的死灵召唤师，在三层随机迷宫中击败怪物、提取亡灵、构筑阵容，最终击败威胁世界的迷宫 Boss。

### 1.2 核心参考方向

- 战斗表现：暗黑地牢式横向站位回合战斗。
- 路线结构：杀戮尖塔式分支路线选择。
- 成长爽点：击败怪物后将其转化为自己的亡灵队友。
- 构筑重点：主人公技能、亡灵阵容、装备、遗物、资源消耗共同形成流派。

### 1.3 基础规格

- 平台：Steam。
- 画面：2D 像素，斜侧视角，横向战斗队列。
- 界面：非卡牌界面，使用技能栏、队列、状态栏和地图节点。
- 单局时长：约 60 分钟。
- 单局结构：3 层迷宫，每层 6-8 个房间，每层末尾必定 Boss。
- 死亡规则：死亡后无保留，完全重开。
- 玩家队伍：主人公固定占 1 个位置，最多携带 3 个亡灵，合计最多 4 个单位。
- 敌方队伍：最多 4 个单位。

## 2. 设计支柱

### 2.1 击败即收编

每个敌人都不仅是战斗障碍，也是潜在队友。玩家在战斗后看到敌人尸体时，会自然产生判断：是否消耗法力尝试提取？是否为了一个更适合当前构筑的亡灵放弃旧队友？

### 2.2 阵容构筑高于单纯数值成长

玩家的强度不只来自等级和装备，而来自：

- 主人公技能路线。
- 亡灵职业搭配。
- 亡灵品质与成长。
- 站位与技能目标限制。
- 遗物和装备触发条件。
- 是否愿意牺牲亡灵换取爆发。

### 2.3 永久死亡制造取舍

亡灵死亡后永久消失。亡灵是战力，也是消耗品。玩家需要在保住核心亡灵、牺牲低价值亡灵、追求新亡灵之间做决策。

### 2.4 路线选择决定构筑节奏

地图路线不是单纯前进。玩家需要判断：

- 当前阵容能否挑战精英？
- 是否需要休息点恢复？
- 是否去亡灵强化房提升核心亡灵？
- 是否进商店购买遗物、装备或随机亡灵？
- 是否冒险进入陷阱房或事件房换取高收益？

## 3. 核心循环

### 3.1 单局循环

1. 开始游戏。
2. 进入迷宫入口。
3. 神秘导师给予本层三选一特殊奖励。
4. 进入分支地图。
5. 选择路线节点。
6. 进入房间：战斗、事件、商店、宝箱、祭坛、休息点、亡灵强化房、陷阱房等。
7. 战斗中按照速度顺序行动，玩家为主人公和亡灵选择技能。
8. 战斗胜利后获得经验、金币、装备、遗物、资源。
9. 选择是否消耗法力提取亡灵。
10. 若亡灵总数超过 3 个，选择舍弃的亡灵。
11. 分配升级属性点，强化技能或亡灵。
12. 继续选择路线。
13. 击败本层 Boss 后进入下一层。
14. 三层全部通关后完成本局。

### 3.2 战斗后奖励顺序

建议固定为：

1. 结算经验和金币。
2. 显示掉落奖励。
3. 显示可提取尸体。
4. 玩家选择是否提取。
5. 提取成功后显示亡灵品质和技能。
6. 若队伍超上限，进入亡灵取舍界面。
7. 进入成长界面：属性加点、技能强化、亡灵升级。
8. 返回地图。

这样可以让“提取亡灵”成为每场战斗后的核心仪式感。

## 4. 主人公系统

### 4.1 主人公定位

主人公是队伍核心，必须上场，占据 4 个站位中的 1 个。主人公既能亲自输出，也能通过亡灵形成军团优势。

主人公死亡即本局失败。亡灵全部死亡但主人公存活时，游戏继续。

### 4.2 主属性

| 属性 | 作用 |
| --- | --- |
| 攻击 | 提高物理技能、武器攻击、斩击类技能伤害 |
| 防御 | 降低受到的直接伤害 |
| 法力值 | 当前可用法力，用于释放技能与战后提取亡灵 |
| 魔法强度 | 提高魔法技能、诅咒、召唤强化和治疗效果 |
| 魔法上限 | 决定最大法力，并影响提取灵魂成功率 |
| 速度 | 决定行动顺序，影响先手和部分速攻流技能 |
| 暴击率 | 决定暴击概率，适合爆发流和刺杀类技能 |

### 4.3 升级加点

主人公升级时获得属性点，由玩家自由分配。

建议初版规则：

- 每级获得 3 点属性点。
- 单项属性每级最多投入 2 点，避免极端堆叠过早破坏平衡。
- 每 3 级获得 1 次技能强化机会。
- 每层 Boss 后额外获得 1 次核心强化机会。

### 4.4 属性成长建议

初始属性建议：

| 属性 | 初始值 |
| --- | ---: |
| 生命 | 80 |
| 攻击 | 10 |
| 防御 | 5 |
| 法力值 | 40/40 |
| 魔法强度 | 10 |
| 魔法上限 | 40 |
| 速度 | 10 |
| 暴击率 | 5% |

注意：生命值虽然不是用户已列主属性，但战斗系统需要生命资源。生命可以作为装备、遗物和等级自动成长属性，不一定进入玩家主动加点列表。

## 5. 亡灵召唤系统

### 5.1 基础规则

- 每种怪物都可以被提取为亡灵。
- 同一种怪物可以重复收集。
- 亡灵占队伍上限，最多 3 个。
- 亡灵死亡后永久消失。
- Boss 可以被召唤，但成为削弱版。
- 进入迷宫后，前两个普通怪物 100% 提取成功，用于保证玩家尽快获得基础队伍。

### 5.2 提取灵魂流程

战斗胜利后，所有被击杀敌人进入“可提取列表”。

玩家选择一个尸体，消耗当前法力尝试提取：

- 成功：获得该怪物对应亡灵，并进行品质随机。
- 失败：不获得亡灵，消耗的法力不返还。
- 放弃：不消耗法力，继续前进。

建议初版限制：

- 每场战斗最多成功提取 1 个亡灵。
- 每个尸体只能尝试 1 次。
- 若玩家当前法力不足最低提取消耗，则不能提取。

这样可以避免战斗后反复抽取导致队伍更新过快。

### 5.3 提取成功率公式

推荐公式：

```text
最终成功率 = clamp(5%, 95%,
  基础成功率
  + 魔法上限加成
  + 魔法强度加成
  + 提取修正
  - 怪物灵魂抗性
)
```

其中：

```text
魔法上限加成 = min(20%, floor((魔法上限 - 40) / 10) * 2%)
魔法强度加成 = min(10%, floor((魔法强度 - 10) / 10) * 2%)
```

基础成功率：

| 敌人类型 | 基础成功率 |
| --- | ---: |
| 普通怪物 | 80% |
| 精英怪物 | 60% |
| Boss | 30% |

怪物灵魂抗性建议：

| 敌人类型 | 灵魂抗性范围 |
| --- | ---: |
| 普通怪物 | 0%-15% |
| 精英怪物 | 10%-25% |
| Boss | 25%-45% |

提取修正来源：

- 遗物：例如“裂魂灯”使普通怪提取 +10%。
- 事件：例如祭坛祝福使下一次提取 +20%。
- 道具：例如“亡灵核心”使 Boss 提取 +10%。
- 负面状态：例如诅咒事件使本层提取 -10%。

### 5.4 提取消耗

提取消耗当前法力，而不是最大法力。

建议初版：

| 敌人类型 | 法力消耗 |
| --- | ---: |
| 普通怪物 | 12 |
| 精英怪物 | 20 |
| Boss | 30 |

可根据怪物等级增加：

```text
最终法力消耗 = 基础消耗 + 当前层数 * 3
```

设计意图：法力同时用于战斗技能和战后提取，玩家不能无脑把法力全部用于输出。

### 5.5 亡灵品质

品质决定初始属性、成长率和技能数量。

品质等级：

1. 普通
2. 稀有
3. 史诗
4. 金色

品质效果：

| 品质 | 属性倍率 | 技能数量 | 额外特性 |
| --- | ---: | --- | --- |
| 普通 | 80% | 1 个主动技能 | 无 |
| 稀有 | 100% | 1 个主动技能 + 1 个被动 | 保留一个怪物特色 |
| 史诗 | 120% | 2 个主动技能 + 1 个被动 | 获得强化特性 |
| 金色 | 145% | 2 个主动技能 + 2 个被动 | 获得专属亡灵词条 |

品质随机建议：

| 来源 | 普通 | 稀有 | 史诗 | 金色 |
| --- | ---: | ---: | ---: | ---: |
| 普通怪 | 70% | 25% | 5% | 0% |
| 精英怪 | 35% | 45% | 18% | 2% |
| Boss | 0% | 50% | 40% | 10% |

道具和遗物可以改变品质结果。例如“镀金魂匣”让下一次提取品质至少为稀有。

### 5.6 Boss 亡灵削弱规则

Boss 被提取后不能完整保留 Boss 强度。

建议规则：

- 生命、攻击、防御、速度调整为原 Boss 的 45%-60%。
- 多动能力删除或改为低频被动。
- 保留 1 个代表性主动技能。
- 保留 1 个弱化版 Boss 特性。
- 不能再次被融合为普通亡灵材料。

示例：

```text
Boss 原技能：一回合行动 3 次。
亡灵版本：每 3 回合获得一次额外行动。
```

## 6. 亡灵成长系统

### 6.1 亡灵升级

亡灵随战斗获得经验。

建议：

- 上场亡灵获得 100% 经验。
- 未上场但携带的亡灵获得 50% 经验。
- 死亡的亡灵不获得经验。

亡灵升级提升生命、攻击、防御、速度等基础属性，但成长幅度低于主人公。

### 6.2 亡灵进化

进化用于提升亡灵品质或解锁技能位。

消耗资源：

- 灵魂碎片：普通强化资源。
- 魔力结晶：技能强化资源。
- 亡灵核心：进化和品质提升资源。

建议用途：

| 资源 | 用途 |
| --- | --- |
| 灵魂碎片 | 亡灵升级、属性强化、低级融合 |
| 魔力结晶 | 主人公技能强化、亡灵技能强化、装备附魔 |
| 亡灵核心 | 亡灵进化、提升品质、Boss 亡灵强化 |

### 6.3 亡灵融合

融合用于处理重复怪物和淘汰亡灵。

推荐规则：

- 同种亡灵融合：提升等级上限或品质进度。
- 同职业亡灵融合：继承少量属性或随机获得一个职业词条。
- 不同职业亡灵融合：获得灵魂碎片，不推荐直接生成新亡灵，避免系统过度复杂。

### 6.4 亡灵装备

主人公和亡灵都能装备：

- 武器
- 护甲
- 戒指

建议限制：

- 主人公可装备 1 武器、1 护甲、2 戒指。
- 亡灵可装备 1 武器或 1 护甲或 1 戒指，三选一。

这样可以让装备分配有取舍，不会让 3 个亡灵全部堆满装备导致管理负担过重。

## 7. 战斗系统

### 7.1 战斗队列

战场分为我方 4 个站位和敌方 4 个站位。

我方：

- 主人公必须上场。
- 亡灵最多 3 个。
- 空位允许存在。

敌方：

- 最多 4 个单位。
- 可以出现 1 个 Boss + 多个小怪。
- 可以出现召唤物。

### 7.2 站位规则

站位编号从前到后为 1-4。

虽然所有位置都能放置任意单位，但技能会受到站位影响：

- 近战技能通常只能从 1-2 号位释放，攻击敌方 1-2 号位。
- 远程技能通常能从 2-4 号位释放，攻击敌方 2-4 号位。
- 法术技能通常站位限制较少，但法力消耗更高。
- 控制技能可以针对前排或后排。
- 位移技能可以推、拉、换位，打乱敌我技能可用性。

设计意图：站位不是职业绑定，而是技能构筑限制。

### 7.3 行动顺序

每回合开始时，根据所有存活单位速度排序。

建议：

```text
行动值 = 速度 + random(0, 3)
```

行动值高者先行动。相同则玩家单位优先。

每个单位每回合行动 1 次。技能无冷却、无怒气、无行动点，但消耗法力或其他资源。

### 7.4 技能资源

技能消耗：

- 主人公技能主要消耗法力。
- 亡灵技能通常不消耗法力，但强技能可能消耗主人公法力或亡灵自身生命。
- 献祭类技能消耗亡灵生命或直接牺牲亡灵。
- 速攻类技能消耗亡灵行动机会，换取主人公额外行动或加速。

### 7.5 伤害公式

推荐初版公式：

```text
物理伤害 = 技能倍率 * 攻击 * (100 / (100 + 目标防御))
魔法伤害 = 技能倍率 * 魔法强度 * (100 / (100 + 目标魔法抗性))
最终伤害 = 基础伤害 * 暴击修正 * 易伤修正 * 随机浮动
```

其中：

- 暴击修正：暴击时 150%。
- 易伤修正：目标易伤时受到伤害 +30%。
- 随机浮动：90%-110%。

如果暂时不设置“魔法抗性”，可以用防御同时处理物理和魔法减伤，但长期建议拆出魔抗，方便法师型怪物和反魔亡灵设计。

### 7.6 异常状态

| 状态 | 效果 |
| --- | --- |
| 中毒 | 回合开始受到固定或百分比伤害，可叠层 |
| 流血 | 行动后受到物理持续伤害，可叠层 |
| 燃烧 | 回合结束受到魔法伤害，并可扩散到相邻单位 |
| 眩晕 | 跳过下一次行动，Boss 对眩晕有抗性 |
| 恐惧 | 降低攻击和速度，概率无法选择攻击技能 |
| 诅咒 | 降低防御或治疗效果，可与死灵技能联动 |
| 易伤 | 受到伤害提高，适合爆发窗口 |

建议持续时间：

- 普通状态：2-3 回合。
- 强控制：1 回合。
- Boss 受到控制时持续时间减半或改为抗性累计。

## 8. 主人公技能系统

### 8.1 技能获得来源

主人公技能可以通过以下方式获得：

- 事件房。
- 祭坛。
- 商店。
- 遗物。
- Boss 奖励。
- 提取亡灵时概率获得该怪物的技能记忆。

### 8.2 技能分类

主人公技能分为 5 个方向：

1. 暗影斩击：主人公亲自输出。
2. 死灵召令：强化亡灵、指挥亡灵、恢复亡灵。
3. 灵魂提取：提高提取成功率、获得额外资源。
4. 诅咒控制：削弱敌人、制造状态、为亡灵创造机会。
5. 献祭禁术：牺牲亡灵换取爆发、治疗或行动优势。

### 8.3 初始技能建议

主人公初始拥有 4 个技能：

| 技能 | 消耗 | 可用站位 | 目标 | 效果 |
| --- | ---: | --- | --- | --- |
| 影刃 | 0 法力 | 1-3 | 敌方 1-2 | 造成 100% 攻击伤害 |
| 灵魂箭 | 4 法力 | 1-4 | 敌方 1-4 | 造成 90% 魔法伤害 |
| 死灵命令 | 6 法力 | 1-4 | 我方亡灵 | 目标亡灵本回合伤害 +30% |
| 站起来 | 10 法力 | 1-4 | 亡灵队伍 | 召唤已携带但未上场的亡灵进入空位，或复苏一个濒死亡灵至 25% 生命 |

说明：“站起来”不是战后提取，而是战斗内的死灵指挥技能。战后提取仍由“提取灵魂”被动处理。

### 8.4 中高级技能示例

| 技能 | 流派 | 消耗 | 效果 |
| --- | --- | ---: | --- |
| 君主领域 | 亡灵流 | 16 法力 | 全体亡灵获得攻击、防御、速度提升，持续 3 回合 |
| 灵魂献祭 | 献祭流 | 0 法力 | 牺牲一个亡灵，主人公恢复法力并对敌方前排造成大量伤害 |
| 影之换位 | 速攻流 | 6 法力 | 主人公与一个亡灵交换位置，主人公获得速度提升 |
| 暗影处刑 | 爆发流 | 12 法力 | 对易伤、恐惧或诅咒目标造成高额伤害 |
| 亡者战旗 | 亡灵流 | 14 法力 | 召唤战旗，亡灵行动时恢复少量生命 |
| 魂链束缚 | 控制流 | 8 法力 | 拉动敌方后排，并施加诅咒 |
| 魔力汲取 | 通用 | 6 法力 | 造成低伤害，若击杀目标则恢复法力 |
| 王之威压 | 控制流 | 15 法力 | 敌方全体恐惧，低生命敌人额外易伤 |

## 9. 亡灵技能系统

### 9.1 亡灵技能原则

亡灵技能比主人公少，但职业辨识度更强。亡灵不应只是数值单位，而应提供构筑组件。

亡灵技能来源：

- 怪物原技能的弱化版。
- 亡灵品质解锁的被动。
- 进化获得的强化技能。
- 融合继承的职业词条。

### 9.2 亡灵职业类型

| 职业 | 定位 | 典型技能 |
| --- | --- | --- |
| 坦克 | 承伤、保护、嘲讽 | 护卫、嘲讽、减伤 |
| 输出 | 稳定伤害 | 重击、连击、破甲 |
| 治疗 | 回复、净化 | 治疗、驱散、持续恢复 |
| 控制 | 打断、眩晕、位移 | 眩晕、拉拽、恐惧 |
| 召唤 | 召唤小单位 | 虫群、图腾、临时仆从 |
| 刺客 | 高速爆发 | 背刺、处刑、闪避 |
| 弓箭手 | 后排输出 | 穿刺箭、标记、压制 |
| 法师 | 范围伤害、元素状态 | 火球、燃烧、诅咒 |

### 9.3 亡灵行动代价

为强化策略构筑，可以加入“亡灵行动代价”机制：

- 普通技能：亡灵自己行动时释放。
- 指令技能：主人公技能触发亡灵立即释放。
- 牺牲技能：亡灵失去生命或死亡，换取强效果。
- 让渡技能：亡灵跳过本回合行动，给主人公加速、法力或额外行动。

这会让“速攻流”和“献祭流”有明确操作空间。

## 10. 构筑流派

### 10.1 爆发流

核心思路：亡灵提供易伤、控制、标记和保护，主人公亲自造成主要伤害。

关键属性：

- 攻击
- 暴击率
- 速度
- 法力值

关键技能：

- 暗影处刑
- 王之威压
- 影之换位
- 死灵命令

关键亡灵：

- 控制型亡灵
- 弓箭手标记亡灵
- 坦克保护亡灵

### 10.2 献祭流

核心思路：把亡灵当作可消耗资源，用牺牲换取伤害、治疗、法力或复活窗口。

关键属性：

- 魔法强度
- 魔法上限
- 防御

关键技能：

- 灵魂献祭
- 亡者契约
- 血魂回响
- 站起来

关键亡灵：

- 低成本召唤物
- 死亡触发被动亡灵
- 坦克亡灵

风险：若献祭过度，Boss 战前阵容会崩。

### 10.3 速攻流

核心思路：亡灵牺牲自己的行动机会，为主人公提供速度、额外行动或连续爆发。

关键属性：

- 速度
- 攻击
- 暴击率

关键技能：

- 影之换位
- 疾影命令
- 死灵加速
- 魔力汲取

关键亡灵：

- 刺客亡灵
- 弓箭手亡灵
- 可让渡行动的辅助亡灵

### 10.4 亡灵流

核心思路：主人公作为军团核心，围绕亡灵搭建完整阵容：坦克、输出、治疗、控制。

关键属性：

- 魔法上限
- 魔法强度
- 防御

关键技能：

- 君主领域
- 死灵命令
- 亡者战旗
- 魂链束缚

关键亡灵：

- 坦克 + 治疗 + 输出
- 控制 + 输出 + 召唤
- Boss 亡灵 + 辅助 + 保护

这是游戏默认主流派，最能体现标题“Summon Maze”。

## 11. 地图与房间系统

### 11.1 地图结构

- 每层为分支路线地图。
- 玩家不能回头。
- 无战争迷雾。
- 玩家能看到前方房间类型。
- 每层 6-8 个房间后进入 Boss。

### 11.2 房间类型

| 房间 | 功能 |
| --- | --- |
| 普通战斗 | 基础成长、提取普通亡灵 |
| 精英战斗 | 高风险高收益，掉落遗物概率高 |
| Boss 房 | 每层终点，通关后进入下一层 |
| 事件房 | 随机选择，可能获得技能、资源、诅咒或亡灵 |
| 商店 | 购买遗物、装备、经验点、随机亡灵 |
| 宝箱 | 获得装备、金币、遗物或资源 |
| 祭坛 | 牺牲资源换取强化，也可能附带诅咒 |
| 休息点 | 恢复生命、法力，或强化技能 |
| 亡灵强化房 | 升级、进化、融合亡灵 |
| 陷阱房 | 造成损失，但可能给高价值奖励 |

### 11.3 每层开始奖励

每层开始时，神秘导师提供三选一奖励。

奖励类型示例：

- 本层第一次提取成功率 +20%。
- 立即获得 1 个随机普通亡灵。
- 主人公获得 1 个技能。
- 获得 1 件随机装备。
- 获得 1 个遗物，但本层敌人生命 +10%。
- 亡灵死亡时返还灵魂碎片。
- 本层商店价格 -20%。

设计意图：开局奖励决定玩家本层路线偏好。

## 12. 装备、遗物与资源

### 12.1 装备

装备部位：

- 武器
- 护甲
- 戒指

装备可给主人公或亡灵使用。

装备词条示例：

- 攻击 +X
- 防御 +X
- 速度 +X
- 暴击率 +X%
- 魔法强度 +X
- 亡灵伤害 +X%
- 提取成功率 +X%
- 使用献祭技能后获得护盾

### 12.2 遗物

遗物是本局永久被动。

遗物示例：

| 遗物 | 效果 |
| --- | --- |
| 裂魂灯 | 普通怪提取成功率 +10% |
| 王冠碎片 | 每有 1 个亡灵存活，主人公伤害 +5% |
| 血色契约 | 亡灵死亡时主人公恢复 10 法力 |
| 黑铁号角 | 战斗开始时全体亡灵获得 1 回合攻击提升 |
| 破碎魂匣 | 第一次提取失败时返还一半法力 |
| 空壳戒律 | 队伍有空位时，主人公速度 +20% |
| 腐朽圣印 | 敌方被诅咒时受到亡灵伤害 +20% |

- 购买经验点。

| 灵魂碎片 | 提取失败、分解亡灵、战斗奖励 | 亡灵升级、融合、普通强化 |
| 魔力结晶 | 精英、Boss、祭坛、宝箱 | 技能强化、装备附魔、法术遗物激活 |
| 亡灵核心 | Boss、精英、稀有事件 | 亡灵进化、品质提升、Boss 亡灵强化 |

## 13. 关卡主题与敌人设计

### 13.1 第一层：野兽丛林

主题：腐化森林、兽群、毒性植物、原始图腾。

敌人示例：

| 敌人 | 职业 | 特点 |
| --- | --- | --- |
| 獠牙狼 | 刺客 | 高速度，攻击后排 |
| 铁皮野猪 | 坦克 | 高防御，冲撞前排 |
| 毒鳞蛇 | 控制/持续伤害 | 中毒，降低速度 |
| 森林萨满 | 治疗/法师 | 治疗野兽，施加诅咒 |
| 藤蔓妖 | 控制 | 拉拽、缠绕、燃烧弱点 |

Boss 方向：

```text
腐根兽王
类型：高数值 + 召唤
机制：召唤藤蔓，占据敌方空位；生命低于 50% 后获得多动。
亡灵版本：保留“召唤藤蔓”或“兽王咆哮”其一。
```

### 13.2 第二层：陨落圣殿

主题：破败圣殿、堕落骑士、失控圣像、反死灵力量。

敌人示例：

| 敌人 | 职业 | 特点 |
| --- | --- | --- |
| 堕落卫士 | 坦克 | 护卫后排，反击 |
| 盲眼弩手 | 弓箭手 | 标记主人公，穿刺攻击 |
| 断誓祭司 | 治疗/控制 | 治疗敌方，驱散负面状态 |
| 圣像碎片 | 法师 | 范围魔法，降低法力 |
| 忏悔刺客 | 刺客 | 隐匿后攻击低生命目标 |

Boss 方向：

```text
堕落圣裁者
类型：控制 + 高防御
机制：审判标记、眩晕、护盾阶段。
亡灵版本：保留“审判标记”，但护盾大幅削弱。
```

### 13.3 第三层：黑暗虫穴

主题：地下虫巢、黑暗孵化、吞噬、群体压迫。

敌人示例：

| 敌人 | 职业 | 特点 |
| --- | --- | --- |
| 深巢工虫 | 召唤/杂兵 | 死亡时生成灵魂碎片 |
| 裂颚兵虫 | 输出 | 连击，流血 |
| 毒腺虫 | 法师 | 中毒、燃烧弱点 |
| 护巢甲虫 | 坦克 | 高防御，保护女王单位 |
| 黑翼猎虫 | 刺客 | 高速，攻击后排 |

最终 Boss 方向：

```text
深巢黑后
类型：多动 + 召唤 + 阶段变化
阶段 1：召唤虫群，压迫队伍站位。
阶段 2：吞噬召唤物恢复生命。
阶段 3：每回合多次行动，并对低生命单位执行处刑。
亡灵版本：通关后可作为展示或特殊模式奖励；普通单局内不建议继续使用。
```

## 14. Boss 机制原则

Boss 不应只是血厚伤高。每层 Boss 至少有一个明确考点：

- 第一层：是否能处理召唤物和前排压力。
- 第二层：是否能突破防御、处理控制。
- 第三层：是否能应对多动、召唤和处刑。

Boss 类型可以分为：

- 多动型：一回合多次行动。
- 高数值型：高防御高攻击，考验持续输出和减防。
- 控制型：多眩晕、恐惧、站位干扰。
- 召唤型：不断制造小怪，考验范围伤害。

## 15. 平衡目标

### 15.1 单局节奏

目标单局约 60 分钟：

| 内容 | 数量 | 单次时长 | 合计 |
| --- | ---: | ---: | ---: |
| 普通/精英战斗 | 12-16 场 | 2-4 分钟 | 30-45 分钟 |
| Boss 战 | 3 场 | 4-7 分钟 | 12-18 分钟 |
| 事件/商店/强化 | 6-8 次 | 1-2 分钟 | 8-12 分钟 |

### 15.2 难度曲线

- 第一层：确保玩家获得基础亡灵，学习提取和站位。
- 第二层：开始检验构筑完整性，亡灵死亡风险提高。
- 第三层：要求玩家拥有明确流派和稳定阵容。

### 15.3 提取系统目标

理想体验：

- 普通怪提取比较稳定，用于补充阵容。
- 精英怪提取让玩家兴奋，但不是必得。
- Boss 提取是高风险高期待。
- 魔法上限投入应明显提高提取体验，但不能保证无脑成功。

## 16. 后续需要继续补充的内容

下一步建议优先补这几块：

1. 主人公完整技能树：每个流派 8-12 个技能。
2. 第一层怪物清单：至少 8 个普通怪、3 个精英、1 个 Boss。
3. 亡灵模板表：每种怪物转化后的属性、技能、品质变化。
4. 遗物池：普通、稀有、Boss、商店、事件遗物各 10 个。
5. 装备词条表：武器、护甲、戒指的主词条和副词条。
6. 事件房文本与选项：至少 20 个事件。
7. 数值原型：生命、伤害、经验、金币、掉落概率。
8. UI 原型：地图界面、战斗界面、战后提取界面、亡灵管理界面。

## 17. 当前版本的设计结论

《Summon Maze》的核心卖点应集中在“把敌人变成阵容组件”上。暗黑地牢式横向战斗提供站位和状态策略，杀戮尖塔式路线提供宏观取舍，而亡灵提取、亡灵死亡、亡灵成长与主人公技能共同构成独立辨识度。

当前最重要的设计风险是：

- 亡灵数量和技能过多，导致管理复杂。
- 提取成功率过低会让核心卖点失落。
- 提取成功率过高会让选择失去重量。
- 主人公太强会压过亡灵系统。
- 亡灵太强会让主人公变成旁观者。

因此初版应坚持：主人公是核心决策者，亡灵是构筑组件；玩家赢在搭配，而不是单个单位数值碾压。
